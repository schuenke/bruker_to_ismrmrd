# bruker_to_ismrmrd

Convert Bruker MRI raw data to [ISMRMRD](https://ismrmrd.github.io/) format.

## Installation

```bash
pip install bruker_to_ismrmrd
```

For development:

```bash
git clone https://github.com/schuenke/bruker_to_ismrmrd.git
cd bruker_to_ismrmrd
pip install -e .[dev]
pre-commit install
```

## Usage

```python
import bruker_to_ismrmrd
```
